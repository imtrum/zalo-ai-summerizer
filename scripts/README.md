# Scripts

| Command | Purpose |
| --- | --- |
| `python scripts/ui.py` | Launch the desktop app |
| `python scripts/run_summarization.py` | Run headless summarization |
| `python scripts/refresh_targets.py` | Discover and save selected targets |
| `python scripts/demos.py mock` | Summarize sample data with the mock provider |
| `python scripts/demos.py json` | Print sample messages |
| `python scripts/demos.py gemini` | Run a Gemini summarization example |
| `python scripts/demos.py batch` | Show sample message batches |
| `python scripts/diagnostics.py open-browser` | Open Zalo Web |
| `python scripts/diagnostics.py chat-list` | Inspect conversation rows and scrolling |
| `python scripts/diagnostics.py messages` | Check collection for one conversation |
